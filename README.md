# 📍 Voz do Bairro - MVP

Este repositório contém o código do protótipo visual (MVP) do projeto **Voz do Bairro**, desenvolvido como parte da Etapa 1 do curso de Análise e Desenvolvimento de Sistemas (UNIVALI).

## 🎯 Sobre o Projeto
O "Voz do Bairro" é uma plataforma colaborativa focada em zeladoria urbana. O objetivo é permitir que cidadãos registrem falhas de infraestrutura (postes apagados, buracos, lixo irregular) em um mapa aberto e apoiem as demandas dos vizinhos, dando peso coletivo às solicitações.

## 💻 Tecnologias Utilizadas no Protótipo Visual
- **HTML5 e CSS3:** Estrutura e estilização da interface.
- **JavaScript:** Lógica de manipulação do modal e filtros.
- **Leaflet.js:** Biblioteca open-source para renderização do mapa interativo.
- **OpenStreetMap:** Base cartográfica aberta.
